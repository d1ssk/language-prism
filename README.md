# language prism

同じ内容を9言語で読み、聞き、比べるための語学学習サイトです。日常表現から文法の例文、文学・思想・科学の文章まで、意味のまとまりごとに並べて学べます。

- **Practical**：日常の場面や短い会話で使う表現
- **Grammar**：文法・構文ごとの例文
- **Library**：文学・思想・科学などの文章

対象言語は、日本語・英語・スペイン語・フランス語・ドイツ語・ロシア語・アラビア語・中国語・韓国語。画面表示と語彙・文法の解説は日本語・英語に対応しています。アラビア語にはラテン文字転写、中国語には声調付きの拼音を添えています。

音声がある文は、個別にも連続でも再生でき、速度や文間のポーズを調整できます。読み表記や音声の使い方をまとめた学習ガイドも用意しています。

教材・解説・音声は順次整備中です。

セットアップ、教材の追加、音声生成などの手順は [開発ガイド](docs/DEVELOPMENT.md) を参照してください。
