# 日本語・英語の画面構成

画面の言語（ja / en）と、学習する本文の9言語は別に管理します。

## URL

```text
/                         日本語ホームへ移動
/ja/                      日本語ホーム
/ja/practical/            Practical一覧
/ja/grammar/              Grammar一覧
/ja/library/              Library一覧
/ja/guide/                表記・学習ガイド
/ja/read/<slug>/          記事
/en/                      English home
/en/practical/            Practical collection
/en/grammar/              Grammar collection
/en/library/              Library collection
/en/guide/                Notation and study guide
/en/read/<slug>/          Article
```

ページ右上の「日本語 / English」は、同じ一覧・同じ記事の言語版に移動します。JavaScriptが無効でも動作します。`/` の既定は日本語で、自動的なブラウザ言語判定やCookie保存は行いません。以前の `/practical/`, `/grammar/`, `/library/`, `/read/<slug>/` は日本語版への静的リダイレクトとして残しています。

GitHub Pagesのサブパスも維持します。例えばbaseが `/language-prism/` なら `/language-prism/en/library/` になります。public/localの両モードで同じURL構造を使います。

## ソース構造

```text
src/
├── pages/
│   ├── index.astro                 # / → /ja/
│   ├── practical.astro             # 旧URL → /ja/practical/
│   ├── grammar.astro               # /grammar/ → /ja/grammar/
│   ├── library.astro               # 旧URL → /ja/library/
│   ├── read/[slug].astro           # 旧記事URL → /ja/read/<slug>/
│   └── [locale]/                   # ja・enを生成する共通テンプレート
│       ├── index.astro
│       ├── [collection].astro      # practical・grammar・library
│       ├── guide.astro             # 読み表記・共通の注・参考資料
│       └── read/[slug].astro
├── i18n/
│   ├── index.ts                    # UI言語・文言参照・変数の置換
│   ├── ja.ts                       # 日本語の本文と画面文言
│   └── en.ts                       # 英語の本文と画面文言
├── layouts/Layout.astro            # html lang・言語切替・共通枠
└── components/                     # 共通の表示部品
```

画面のHTMLやCSSを日英で別々にコピーしません。`src/pages/[locale]/` の1組から、両言語の静的ページを生成します。見た目の変更は共通テンプレートに、説明文・ボタン文言の変更は `src/i18n/ja.ts` と `en.ts` に反映します。英語辞書のキーは日本語辞書の型に合わせ、テストでもキー・埋め込み変数の一致を確認します。

ホームの9言語の列挙と記事本文の順序は、`config/languages.json` を基準に `displayLanguages()` で決めます。日本語版は日本語→英語、英語版は英語→日本語が先頭で、残り7言語の順序は共通です。意味単位・記事全体の連続再生も画面の順序に従います。保存データと音声生成の基準順序・言語コードは変更しません。

## 記事・音声の配置

```text
content/public/<type>/<id>/content.json
media/public/<type>/<id>/<unit>/<lang>.mp3

外部privateルート/
├── content/<type>/<id>/content.json
└── media/<type>/<id>/<unit>/<lang>.mp3
```

ここに `ja/` と `en/` のUI用ディレクトリを作る必要はありません。ひとつの記事データを日英両方の画面から参照し、MP3も同じファイルを使用します。公開・非公開の分離、公開成果物のallowlistもそのまま維持しています。

画面文言は辞書に、記事のタイトル・説明・語彙の意味・文法解説・注意書きは同じ記事JSON内の `{ "ja": "…", "en": "…" }` に保存します。従来の単一文字列も引き続き使用できます。学習対象の本文9言語は `text`、音声用の読みは `ttsText` として別に保持します。表示時に該当する説明を選択するだけで、自動翻訳や音声の複製は行いません。Practicalの「ランダム 1」が実例です。詳細は [CONTENT_FORMAT.md](CONTENT_FORMAT.md) を参照してください。

Libraryで標準9言語以外の原文を掲載する場合は、`config/original-languages.json` の表示専用原語を `displayLanguages(locale, originalLanguage)` でUI言語の直後に挿入します。日英ページ間で原文を含む同じ記事データを共有し、音声生成対象の9言語は変えません。
