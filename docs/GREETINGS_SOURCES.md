# 挨拶：使用場面と対応表現の編集メモ

2026-10-27。`content/public/practical/greetings/content.json` は、同じ使用場面を比べる例文集です。単語単位の直訳や、すべての話者・地域で同じ挨拶を使うという主張ではありません。

- [ニュージーランド民族コミュニティ省：Greetings in Korean](https://www.ethniccommunities.govt.nz/resources/information-and-resources-in-other-languages/greetings-in-different-languages/greetings-in-korean)：朝・昼・夜に共通して 안녕하세요 を載せる判断の参考。朝専用の表現が絶対に存在しないという意味にはしていません。
- [日本政府観光局：Mots](https://www.japan.travel/fr/fr/savoir-vivre-au-japon/mots/)：「いただきます」を食べ物への感謝として扱い、Bon appétit と同一視しない説明を確認。
- [国際交流基金：Nihongo de Care-Navi / shokuji](https://eng.nihongodecarenavi.jp/eng/entry_3803.html)：食前・食後の日本語の挨拶と、食事の用意への感謝を確認。
- [韓国国立国語院：세종학당 교재 개발 연구](https://www.korean.go.kr/common/download.do?c_file_name=20b9d6e7-d055-429e-bfe7-f02fe984782c_0.pdf&file_path=reportData&o_file_name=%EC%84%B8%EC%A2%85%ED%95%99%EB%8B%B9+%EA%B5%90%EC%9E%AC+%EA%B0%9C%EB%B0%9C+%EC%97%B0%EA%B5%AC.pdf)：本文191ページ（PDFの199ページ目）の、ごちそうする人への応答例に 잘 먹었습니다 / 잘 먹겠습니다 を確認。

「いただきます」の組は、食べ始める本人の発話として整理しています。他人へ食事を楽しむよう勧める表現や、宗教・家庭の慣習による言葉を、同じ定型句として埋めない編集判断です。`noEquivalent` はその判断と理由を示し、挨拶や食前の言葉自体が存在しないという断定には使いません。

「ごちそうさまでした」の組は、食事を用意してくれた相手へお礼を述べる場面に限定し、各言語の自然な感謝表現を載せています。
